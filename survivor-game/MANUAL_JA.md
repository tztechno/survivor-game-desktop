# CYBER SURVIVORS 遊び方（ゲームマニュアル）

『**CYBER SURVIVORS**』は、押し寄せる無数のサイバーエネミーを薙ぎ払い、自らの機体を強化しながら極限の生存を目指す**見下ろし型オートアタック・サバイバーライクACT**です。

---

## 1. 🚀 ゲームの基本ルール & ゲームフロー

攻撃は全て自動（オートアタック）で行われます。プレイヤーは敵の包囲をすり抜ける位置取りと回避、そして敵が落とす**経験値クリスタル（光る結晶）の回収**に集中します。

```
[敵の包囲を回避・誘導] ➔ [オート武器で撃破] ➔ [光る経験値クリスタル（💎）を拾う] ➔ [レベルアップでビルド強化]
```

### 💎 「経験値クリスタル」とは？
- 敵を倒すと、その場に **青・紫・金色に光るひし形の結晶（💎）** がポロッと落ちます。
- プレイヤー機体で近づくと磁石のように吸い寄せられて回収され、画面最上部の**青いEXPバー（経験値ゲージ）**がたまります。
- ゲージがいっぱいになると**レベルアップ画面が開き、新しい武器や強化スキルを選べます**。

### 基本ステータス & 画面表示
- **LV / EXPゲージ（画面上部）**: 経験値クリスタルを拾うと上昇。満タンでレベルアップ！
- **⏱️ 生存タイマー**: 経過時間。60秒ごとに強力なボスが出現。
- **💀 撃破数 / 💎 スコア**: 倒した敵の数と獲得スコア。
- **インベントリ（画面左下）**: 現在装備中の武器（最大4種）とパッシブ強化チップ（最大5種）。

## 3. ⚔️ 全武器カタログ (Weapons Guide)

最大 **4スロット** まで同時に装備可能。各武器は **最大LV 5** まで強化できます。

| 武器名 | アイコン | 特徴 & 強化方針 |
| :--- | :---: | :--- |
| **マジックミサイル**<br>*(Magic Missile)* | 🔮 | 最も近い敵を自動ロックオンし、高速誘導弾を発射。<br>・LV上昇で同時発射数（最大4発）や貫通力、連射速度が大幅向上。 |
| **オービットブレード**<br>*(Orbital Blades)* | 🛡️ | 自機の周囲を高速旋回するエネルギーの刃。<br>・接近する敵を刻みノックバックさせる鉄壁の防御壁。<br>・LV上昇でブレード数（最大5基）と回転速度が上昇。 |
| **サンダーストライク**<br>*(Thunder Smite)* | ⚡ | 上空からランダムな敵の位置へ高電圧の雷撃を落とす。<br>・着弾地点に広範囲の爆発ダメージを与え、群れを一網打尽にする。<br>・LV上昇で落雷数（最大4発）と爆破半径が増加。 |
| **フレイムオーラ**<br>*(Flame Aura)* | 🔥 | 自機の周囲に常時灼熱のプラズマフィールドを展開。<br>・範囲内に侵入した敵を高速で継続的に焼き尽くす。<br>・LV上昇でフィールド範囲と威力が劇的に拡大。 |
| **バウンド手裏剣**<br>*(Bouncing Shuriken)* | 💠 | 敵から敵へと連続して跳ね返る高速手裏剣。<br>・LV上昇で投擲数と跳ね返り回数（最大9バウンド）が増加。 |

## 4. 🧬 パッシブ強化スキル (Passives Guide)

機体の基本スペックを恒久的に底上げする強化チップ（最大LV 5）。

| パッシブ名 | アイコン | レベルごとの効果詳細 |
| :--- | :---: | :--- |
| **攻撃力ブースト**<br>*(Might)* | ⚔️ | 全武器の与ダメージが **+15% / LV** 増加（最大 +75%）。敵の耐久力が上がる後半の要。 |
| **攻撃速度アップ**<br>*(Haste)* | ⚡ | 全武器の攻撃クールダウンが **-12% / LV** 短縮（最大 -60%）。弾幕密度が飛躍的に向上。 |
| **加速ブーツ**<br>*(Boots)* | 👟 | 移動速度が **+12% / LV** 向上（最大 +60%）。敵の包囲網脱出やボス戦の回避に必須。 |
| **磁力コア**<br>*(Magnet)* | 🧲 | 経験値クリスタル（💎）の回収範囲が **+35% / LV** 拡大（最大 +175%）。安全圏から大量の経験値を吸収可能。 |
| **生体ナノマシン**<br>*(Vitality)* | 💚 | 最大HPが **+25 / LV** 増加し、さらに **毎秒HP自動回復**（最大 HP+125, 回復+4.0/s）。 |

## 5. 👾 エネミー & ボス一覧

- 🔵 **スライム (Slime)**: 基本的な群れ敵。数で圧倒してくるため範囲攻撃で対処。
- 🟣 **サイバーバット (Bat)**: ジグザグに素早く急接近してくる高速敵。
- 🟪 **アーマードゴーレム (Golem)**: 高耐久・重量級の強敵。集中砲火でノックバックさせて撃破。
- 👑 **サイバーボス (Boss)**: **60秒ごと** に出現する黄金の巨大ボス。撃破すると大量の超高額経験値クリスタルをドロップ！

## 6. 💡 サバイバル攻略Tips

1. **円を描くように動く（カイト走法）**:
   - 一直線に逃げると前方を塞がれやすくなります。敵の群れの外周を大きく旋回することで、敵をまとめつつ経験値クリスタルを一箇所に集中投下させることができます。
2. **序盤は武器の集中強化が有利**:
   - 武器を広く浅く取るよりも、メイン武器をLV3〜4まで集中強化すると敵の殲滅テンポが上がり、レベルアップ効率が大幅に向上します。
3. **磁力コアと高火力武器のシナジー**:
   - 敵の大群に近づけない時でも、「磁力コア」があれば遠くの経験値クリスタルを一気に吸い寄せて安全にレベルアップを連鎖できます。
4. **DEMOプレイモードの活用**:
   - タイトル画面の「DEMO PLAY」を押すと、自律AIによるデモプレイを観戦できます。画面クリックですぐに手動操作へ参戦可能です。
